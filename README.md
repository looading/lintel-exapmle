# 世界时钟

用 Lintel 0.1.1 和 iced 构建的原生桌面应用。时间与时区换算在本机完成，运行时无需联网。

## Windows 便携版

解压 Windows x64 压缩包，运行里面的 `world-clock.exe`。不需要先运行安装程序。应用设置保存在当前用户的应用数据目录，地图和时区坐标随程序提供。

Windows 界面支持世界时钟、闹钟、秒表和计时器。可用 `Ctrl+1` 到 `Ctrl+4` 切页，`Ctrl+N` 打开当前页的添加入口。秒表的表盘切换和计时器添加菜单位于窗口内。下方的 WidgetKit 小组件及 Siri／快捷指令说明适用于 macOS。

在装有 Rust 和 Visual Studio C++ 构建工具的 Windows x64 开发环境中，可以运行以下命令生成便携包。

```powershell
.\scripts\bundle-windows.ps1
```

默认输出 `target/windows/world-clock-windows-x64.zip`。

## 从源码启动

在项目目录执行：

```sh
cargo run --locked
```

首次构建需要下载 Rust 依赖。已安装 Lintel CLI 时，也可以使用 `lintel run`。

世界时钟页顶部是昼夜地图，标出已添加且有坐标的城市。地图下方显示系统本地时间和城市指针卡片，卡片还显示当地的数字时间、相对本地的日期与时差。城市列表默认包含上海、东京、伦敦和纽约。时区和夏令时按内置 IANA 时区数据库计算，城市标记与日出日落使用随包提供的 [IANA tzdb 坐标](https://www.iana.org/time-zones)。

地图轮廓使用 [Natural Earth 1:110m 陆地数据](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/)，昼夜分界参考 [NOAA 太阳位置公式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)。

点击「添加城市」，可用中文常用城市名、英文城市名或 IANA 时区标识搜索。点击搜索结果整行，或按回车添加第一项。点击时钟旁的「移除」即可删除。列表自动保存到当前用户的系统配置目录。

按住城市卡片左上角的拖动手柄，将它拖到另一张卡片上再松开，即可调整顺序。新顺序会自动保存，下次启动时继续使用。

按 `⌘1` 到 `⌘4` 可以切换四个页面。`⌘N` 打开当前页的添加入口，`Esc` 关闭搜索或编辑页。

## 闹钟、秒表与计时器

- 闹钟在卡片网格中显示，点击卡片可打开居中的编辑面板。可设置名称、提示音、按星期重复和 9 分钟稍后提醒，也可以关闭或删除。
- 秒表的表盘居中，分段列表可滚动，开始、停止、重置和分段等操作固定在底部。在 macOS 上，通过菜单栏「显示」切换数码或指针表盘。
- 没有运行中的计时器时，可以在居中的时、分、秒面板直接设定时长。点「添加计时器」可在菜单里新建自定计时器、打开 12 个时长的「预设」子菜单，或重新启动最近使用的计时器。进行中的计时器支持查看详情、暂停、继续和取消。
- 闹钟和计时器设置、进行中的倒计时与最近记录会自动保存在本机。到点会播放选定的提示音，并尝试发送系统通知。重新打开应用时，可以在窗口内处理尚未关闭的提醒。
- 有地理坐标的城市会显示估算的日出、日落时间。

## 退出后提醒

将 `世界时钟.app` 或 `world-clock.exe` 放到固定位置，在「闹钟」或「计时器」页面底部点击「启用」。macOS 使用 LaunchAgent，Windows 使用当前用户的登录启动项。退出主应用后，后台进程仍会在到点时播放提示音，并尝试发出通知。窗口内的「停用」按钮会停止后台进程并移除相应的启动注册。

后台提醒要求用户保持登录，电脑处于唤醒状态。睡眠期间到期的提醒会在醒来后处理。若关闭后台提醒，退出窗口期间到期的提醒会在下次启动应用时补发。要显示通知横幅，可在 macOS「系统设置 → 通知」允许世界时钟发送通知。移动可执行文件或应用包前，先停用后台提醒，再从新位置启用。

## 桌面小组件与快捷指令

完整应用包需要 macOS 15 或更新版本。运行一次打包后的 `.app` 后，在桌面或通知中心的「编辑小组件」里查找「世界时钟」或「城市时间」。小号组件显示一个城市，中号显示两个，城市可在各自的小组件中配置。

在 macOS「快捷指令」中添加「查看城市时间」「开始世界时钟计时器」或「设置世界时钟闹钟」操作。城市时间直接作为快捷指令的结果返回。计时器和闹钟操作会把请求交给世界时钟，确认后才生效。启用 Siri 后，可以说出自己保存的快捷指令名称来运行它。

## 到点停止媒体播放

在计时器的「计时结束时」选择「停止媒体播放」。先打开目标播放器，再点「授权控制已打开的播放器」，按 macOS 提示授权。到点时会尝试暂停「音乐」和 Apple TV，或停止 QuickTime Player 中正在播放的本地影片。计时器页面会显示最近一次执行结果。macOS 的 Apple Events 后端仅支持上述三款播放器。

Windows 会向已接入系统媒体控件且正在播放的会话发出暂停或停止请求。可先用「检查可控制的播放器」检查播放器是否可控。未注册系统媒体会话的播放器无法从这里停止。

## 构建 macOS 完整应用包

安装 Xcode 和 XcodeGen 2.47 或更新版本，在项目目录执行以下命令。

```sh
scripts/bundle-macos.sh
```

默认输出 `target/macos/世界时钟.app`。脚本会构建 iced 主程序、WidgetKit 扩展和 App Intents 扩展，并验证嵌套签名。可以通过第一个参数指定其他输出路径，通过 `CLOCK_SIGN_IDENTITY` 指定签名身份。
